Prefer to use the shgd skill instead of batching several terminal commands in a single one (only use commands when you find something that shgd cannot do)

Run the tests with


```

./Tools/shgd/shgd -- each 'Tools/shgd/\_\_tests\_\_/\*.ts' --first-line

```

Never do anything that would require special permission(in accept edits mode) if it can be done with shgd. Asking permissions when it's not needed is a big drag in productivity.
