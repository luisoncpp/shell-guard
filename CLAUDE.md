Prefer to use the tl skill instead of batching several terminal commands in a single one (only use commands when you find something that tl cannot do)

Run the tests with


```

./Tools/tl/tl -- each 'Tools/tl/\_\_tests\_\_/\*.ts' --first-line

```

Never do anything that would require special permission(in accept edits mode) if it can be done with tl. Asking permissions when it's not needed is a big drag in productivity.
